# ⚗️ Фабрика гипотез

Система генерации и приоритизации проверяемых инженерных гипотез по снижению потерь
металла с хвостами обогащения сульфидных руд (Норникель AI Science Hack).

**Демо:** выберите пример (КГМК / НОФ / ТОФ) или загрузите свой `Хвосты*.xlsx`.
Вкладки: Диагностика · Гипотезы (обоснование + цитаты + фидбэк) · Граф знаний · Экономика/KPI · Экспорт.
Элемент 28 = никель (Ni), Элемент 29 = медь (Cu).

## Запуск локально
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## LLM-обоснование (Yandex AI Studio)
Задайте ключ через переменные окружения или `.streamlit/secrets.toml`:
```
YANDEX_API_KEY = "..."
YANDEX_FOLDER_ID = "..."
YANDEX_MODEL = "yandexgpt"
```
Без ключа приложение работает так же: BM25-цитаты из учебников + детерминированные обоснования.

## Архитектура
Интерпретируемый гибрид: Diagnostic Engine (правила на физике процесса) → каталог
гипотез-вмешательств → RAG-обоснование → ранжирование по прозрачной формуле → экспорт.
Каждая гипотеза = диагноз с числами + механизм + цитата + риски + эффект. Ноль галлюцинаций.
