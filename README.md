# Фабрика гипотез

![python](https://img.shields.io/badge/python-3.11-blue)
![streamlit](https://img.shields.io/badge/UI-Streamlit-ff4b4b)
![demo](https://img.shields.io/badge/demo-online-brightgreen)

Инструмент поддержки решений для обогатительной фабрики. По отчёту о хвостах
находит, где и почему теряется металл, и предлагает ранжированные проверяемые
инженерные гипотезы по снижению потерь — с обоснованием, ссылками на литературу,
оценкой эффекта в деньгах и шагами пилотной проверки.

**Живое демо:** https://mqx8z5jx3w6gg3aamhzvnc.streamlit.app/

Данные кейса — обогащение сульфидных руд флотацией (Норникель AI Science Hack).
В отчётах: **элемент 28 = никель**, **элемент 29 = медь**.

---

## Демо за 90 секунд

1. Открой демо → страница **«Анализ»**.
2. Слева выбери фабрику (КГМК / НОФ / ТОФ) — примеры уже встроены. Чтобы попробовать
   загрузку, скачай любой файл из [`data/examples/`](data/examples/) и перетащи его
   в режиме «Загрузить файл».
3. Вкладка **«Диагностика»**: сверху — аудит качества данных, ниже — где теряется
   металл (сростки vs шламы), внизу — «Почему НЕ предлагаем некоторые меры».
4. Вкладка **«Гипотезы»**: ранжированный список; двигай веса слева, чтобы сместить
   приоритет (ценность / реализуемость / новизна / риск).
5. Вкладки **«Экономика»** (матрица «быстрые победы / стратегические») и **«Экспорт»**
   (DOCX / CSV / JSON). Страница **«Валидация»** — сравнение с гипотезами экспертов.

---

## Что делает система

Это **интерпретируемый гибрид**, а не языковая модель поверх данных. Пайплайн:

```
Excel → аудит данных → диагностика (физика процесса) → каталог решений
      → расчёт эффекта по минералогии → ранжирование → обоснование (RAG + LLM) → экспорт
```

- **Диагностика.** Потери раскладываются по классам крупности и минеральным формам:
  металл в сростках (нужно доизмельчение) и раскрытый металл в тонком классе
  (теряется во флотации). Считается «потолок эффекта» — сколько металла извлекаемо.
- **Гипотезы.** Каталог инженерных вмешательств привязан к диагнозу; ранжирование
  по прозрачной формуле с настраиваемыми весами.
- **Эффект.** Считается по реальной минералогии класса (адресуемый металл × доля
  извлечения) и показан диапазоном (пессимистичный / ожидаемый / оптимистичный)
  с уровнем уверенности и основанием коэффициента.
- **Обоснование.** Ссылки на литературу (поиск по корпусу учебников и статей) +
  опциональная языковая модель. **LLM не генерирует новые числа — только связно
  излагает уже посчитанные ядром факты.**
- **Валидация.** Прогон на 4 фабриках против гипотез экспертов: покрытие 89% (24/27),
  плюс дополнительные варианты сверх экспертного списка. Пропуски показаны честно.

## Decision-ready output

Каждая гипотеза — не «идея», а готовый к решению блок:
диапазон эффекта (млн $/год) · реализуемость · новизна · риск · механизм влияния ·
задействованное оборудование · критерий успеха · шаги пилотной проверки · ссылка на источник.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Опционально — текстовые обоснования через Yandex AI Studio
(`.streamlit/secrets.toml` или переменные окружения):
```toml
YANDEX_API_KEY = "..."
YANDEX_FOLDER_ID = "..."
YANDEX_MODEL = "yandexgpt"
```
Без ключа приложение работает так же: цитаты из литературы + детерминированные обоснования.

## Воспроизводимость

- Примеры данных — в `data/examples/` (демо работает без внешних файлов).
- Валидация против эталона — страница «Валидация» в UI или модуль `core/validate.py`.
  Эталонные гипотезы экспертов — `data/knowledge/gold_hypotheses.json`.
- Каталог решений — `data/knowledge/hypotheses.yaml`. Корпус литературы для ссылок —
  `data/parsed/corpus.jsonl`.

## Структура

```
streamlit_app.py        точка входа (навигация)
app_pages/              Главная · Анализ · Валидация · О проекте
core/
  ingest.py             разбор Excel-отчёта о хвостах
  diagnose.py           диагностика + аудит данных + анти-гипотезы
  generate.py           каталог решений + ранжирование
  effect_model.py       расчёт эффекта по минералогии (диапазон + уверенность)
  rag.py                поиск обоснований по корпусу литературы
  llm.py                текстовое обоснование (grounded, без новых чисел)
  validate.py           сравнение с гипотезами экспертов
  economics.py          KPI, извлечение, чувствительность
  feedback.py           учёт оценок экспертов
  graph.py, report.py   граф связей и экспорт
```

## Ограничения (честно)

- Коэффициенты извлечения в модели эффекта — из инженерной практики; уточняются
  лабораторным опробованием (поэтому эффект дан диапазоном).
- Качество выводов зависит от качества отчёта; система проверяет данные, но не
  исправляет их.
- Гипотезы приоритизируют направления, но требуют пилотной проверки на фабрике.
